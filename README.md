Task 3: Responsive Multi-Section Layout

Project Objective
This project is a fully responsive, multi-section landing page built using a mobile-first approach. It serves as the foundational structure for the company’s main website, focusing on clean code, semantic HTML5, and modern CSS layout techniques.

Technologies Used
HTML5: Semantic structure (header, section, main, footer).
CSS3: Flexbox for navigation and alignment; CSS Grid for complex layouts.
JavaScript: Mobile menu toggle functionality.

Features & Responsiveness
Mobile-First Design: Optimized for small screens first, then scaled up.
Dynamic Grid: Mobile: 1 Column
Tablet: 2 Columns
Desktop: 4 Columns
Navigation: Sticky navbar with a functional mobile hamburger menu.
UI/UX: Smooth scrolling, hover effects on cards and buttons, and a consistent color palette.
